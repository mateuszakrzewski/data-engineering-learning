JOIN i test ziarna

Po złączeniu jeden do wielu ziarno wyniku = ziarno strony „wiele". Kolumny strony „jeden" się powtarzają.

Szkielet

SELECT u.traffic_source, COUNT(DISTINCT o.order_id) AS zamowienia
FROM `projekt.zbiór.orders` AS o          -- alias tabeli
JOIN `projekt.zbiór.users`  AS u          -- JOIN = INNER JOIN: tylko pary, które pasują
  ON o.user_id = u.id                     -- warunek dopasowania: klucz obcy = klucz
GROUP BY u.traffic_source;

Test ziarna (przed i po)

1. przedCOUNT(*) = COUNT(DISTINCT klucz) w dołączanej tabeli → klucz unikalny, ziarno się nie zmieni
2. poCOUNT(*) = COUNT(DISTINCT klucz_ziarna) na wyniku złączenia → ziarno zachowane
3. gdy nieSUM/COUNT(*) na kolumnach strony „jeden" są zawyżone (fan-out)

Pułapki

Column name … is ambiguousta sama nazwa kolumny w dwóch tabelach (status, user_id, created_at) → prefiks aliasu
SUM(o.num_of_item) po złączeniu z pozycjamizamówienie z n pozycjami wnosi n·n zamiast n
COUNT(*) jako „zamówienia" po złączeniu z pozycjamiliczy pozycje → COUNT(DISTINCT o.order_id)
