SELECT i ziarno

Pytanie numer jeden do każdej tabeli: co oznacza jeden wiersz?

Szkielet zapytania (kolejność stała)

SELECT kolumna1, kolumna2          -- które kolumny (* = wszystkie)
FROM `projekt.zbiór.tabela`        -- z której tabeli
WHERE kolumna = 'tekst'            -- tylko wiersze, dla których warunek jest prawdziwy
ORDER BY kolumna DESC              -- sortuj; DESC = malejąco (daty: najnowsze na górze)
LIMIT 10;                          -- najwyżej 10 wierszy

Pułapki

'Returned' ≠ 'returned'tekst rozróżnia wielkość liter → 0 wierszy, bez błędu, kod wyjścia 0
status = Returnedbez apostrofów to nazwa kolumny → Unrecognized name
'…' vs `…`apostrof = wartość tekstowa; grawis (BigQuery) = nazwa z myślnikami
SELECT * … LIMIT 10BigQuery czyta kolumny w całości: koszt zależy od kolumn, nie od LIMIT
