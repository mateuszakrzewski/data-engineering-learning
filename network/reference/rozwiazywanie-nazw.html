Rozwiązywanie nazw

Kto zamienia host z connection stringa na adres — i gdzie to sprawdzić.

Reguła. Nazwę rozwiązuje maszyna, na której działa program — nie ta, przy której siedzisz. Kontener ma własny łańcuch, laptop własny.
Narzędzie. getent hosts nazwa pyta tak jak psql/curl. dig pyta tylko serwer DNS.

Łańcuch w Linuksie (Twój laptop)

  1. program psql, curl, sterownik

    Prosi bibliotekę systemową (getaddrinfo) o adres.

  2. /etc/nsswitch.conf kolejność źródeł

    hosts: files mdns4_minimal [NOTFOUND=return] dns · files = /etc/hosts, dns = resolv.conf

  3. /etc/hosts plik: adres nazwa

    127.0.1.1 LEGION · 127.0.0.1 localhost

  4. /etc/resolv.conf do kogo wysłać pytanie DNS

    laptop: 127.0.0.53 (systemd-resolved) · kontener w sieci użytkownika: 127.0.0.11 (DNS Dockera)

  5. serwer DNS i dalej router → resolver rekurencyjny → autorytatywny

    resolvectl status → DNS Servers: 192.168.1.1
